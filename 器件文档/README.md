## 当前硬件阶段

- 显示：ST7789 240×240，RGB565，40 MHz SPI，默认 0°。
- 按键：屏幕不再自带按键，改为 4 个独立轻触键（LEFT/RIGHT/OK/BACK；GPIO21/38 停用）。
- 气体：BME690 已在实际板卡上通过 I²C 识别并采样。
- 语音：LU-03T/SU-03T 模块喇叭接 SPK+/SPK-；ESP32 已通过 GPIO15/GPIO16 UART1 发送提示音，模块端需烧录匹配的串口输入行为。
