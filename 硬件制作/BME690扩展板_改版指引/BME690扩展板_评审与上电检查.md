# BME690 扩展板 v1.0 —— 评审与上电检查

评审对象：`硬件制作\PCB_PCB1_2026-11-19.png`（2 层板，板角 R1.39，丝印 `BME690扩展板 v1.0`）
评审时间：2026-11-19

## 一、没问题的部分

- 封装是 LGA-8，与 BME690（3.0×3.0×0.93mm）一致。
- 两组 4Pin 排针的引脚顺序与博世数据手册一致：
  - 上组：`1 GND` `2 CSB` `3 SDI` `4 SCK`
  - 下组：`1 VDD` `2 GND` `3 VDDIO` `4 SDO`
- 2.54mm 排针间距，能直接插面包板，符合"先模块调试"的用法。

## 二、必须处理的 4 处

### 1. 缺去耦电容（最高优先）

板上**没有任何电容/电阻**。BME690 的 VDD 与 VDDIO 各需要 **100nF**，且要紧靠引脚（≤2mm）。
气体传感器加热瞬间是电流阶跃，没有就近去耦会出现：基线随加热剖面漂移、I²C 偶发 NACK、气体电阻读数跳变。

- 改板：U1 旁加 `C1 100nF（VDD-GND）`、`C2 100nF（VDDIO-GND）`，可选再加 1µF。
- 不改板：面包板上外挂两粒 100nF，一脚接对应电源、一脚接 GND，**越靠近排针越好**。

### 2. 传感器脚下大面积 GND 铺铜 + 密集过孔（对"温度调制"是硬伤）

整板铺 GND 并用大量过孔缝合，一直到 U1 引脚旁边。气体传感的加热板热量会顺着封装和焊盘灌进 PCB 铜皮，后果：

- 设定 300℃，实际气敏层温度偏低，且**随环境温度漂**；
- 多步加热剖面的每一步稳态不可重复 → 你论文里"温度指纹"的可重复性直接被破坏。

改板建议：U1 正下方及周围 **去铜**（禁铺区），四周可加隔热槽；底部（Bottom）在传感器正下方开一个 **Φ1.0~1.5mm 通气孔**，兼顾气体交换与热隔离。

### 3. I²C 模式需要外部跳线

BME690 上电默认按 CSB 电平选接口：**CSB 拉高（VDDIO）→ I²C；CSB 低/悬空 → SPI**。
板上 CSB 只引到排针、没有上拉电阻，所以：

- 用 I²C：`CSB` 必须用杜邦线接 `VDDIO`；
- 地址由 SDO 决定：**SDO→GND = 0x76，SDO→VDDIO = 0x77**，SDO 不能悬空。
- 建议下一版加一个 3Pin 跳线位（CSB 选 VDDIO/GND），丝印标 0x76/0x77。

### 4. 丝印是镜像的，确认放哪一层

图上所有文字（含 `BME690扩展板 v1.0`）都是反的。如果这是 EDA 的**底层视图**就没问题；
如果丝印真的放在 Bottom 层，插上面包板后完全看不见标号，建议丝印移到顶层。

## 三、不改板、现在就能调试的接法

| 扩展板 | 接法 |
|---|---|
| VDD / VDDIO | 3V3，各外挂 100nF 到 GND |
| GND | GND |
| CSB | **短接到 VDDIO**（进 I²C 模式） |
| SDO | 接 GND（地址 0x76） |
| SDI | → ESP32 GPIO8（SDA），加 4.7k 上拉到 VDDIO |
| SCK | → ESP32 GPIO18（SCL），加 4.7k 上拉到 VDDIO |

上电顺序：先量 VDD/VDDIO 是否 3.3V → 读 `chip_id`（应为 **0x61**）→ 读温湿度 → 最后跑 300℃ 加热，看 Rs 从 MΩ 级掉到几十 kΩ 级。

焊接提醒：裸片是 LGA-8，焊盘在底面，必须钢网+锡膏+热风回流（峰值 260℃，焊后锡层高度 ≥50µm），**焊完按手册做 reconditioning**，否则起始基线是偏的。
