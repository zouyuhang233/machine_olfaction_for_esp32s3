# 4 键交互与页面操作

本项目只使用 4 个按键，不依赖触摸、旋钮或屏幕点击。所有页面都遵循“左右选择、确认执行、返回退出”的统一规则。

## 一、按键定义

| 按键 | GPIO | 电气方式 | 通用作用 |
|---|---:|---|---|
| 左键 LEFT | GPIO6 | 内部上拉，按下拉低 | 左移、减小、返回曲线页 |
| 右键 RIGHT | GPIO7 | 内部上拉，按下拉低 | 右移、增大、进入实时监测 |
| 确认 OK | GPIO4 | 内部上拉，按下拉低 | 进入、开始、保存、切换 |
| 返回 BACK | GPIO5 | 内部上拉，按下拉低 | 取消、返回上级、首页进菜单 |

- 按键消抖约 12 ms。
- 左右键支持长按连发，适合音量、亮度和菜单快速移动。
- GPIO21/38 已停用，不再参与交互。
- 换页后约有 180 ms 输入锁，避免一次按键穿透到下一个页面。

## 二、页面矩阵

| 页面 | 左键 | 右键 | 确认 | 返回 |
|---|---|---|---|---|
| 首页 | 无 | 进入实时监测 | 开始检测 | 进入菜单 |
| 实时监测 | 回首页 | 无 | 无 | 回首页 |
| 检测中 | 无 | 无 | 立即完成检测 | 取消并回首页 |
| 结果页 | 无 | 无 | 进入菜单 | 回首页 |
| 菜单 | 卡片左移 | 卡片右移 | 进入当前卡片 | 回首页 |
| 传感器 | 无 | 无 | 无 | 回菜单 |
| 网络 | 无 | 无 | 切换 Wi-Fi 开关 | 回菜单 |
| 蓝牙 | 无 | 无 | 切换 BLE 开关 | 回菜单 |
| 声音 | 焦点左移 | 焦点右移 | 进入/执行当前项 | 回菜单 |
| 显示 | 焦点左移 | 焦点右移 | 进入/执行当前项 | 回菜单 |
| 系统 | 焦点左移 | 焦点右移 | 修改/确认/重启/复位 | 回菜单 |
| 历史 | 上一条记录 | 下一条记录 | 关闭 | 关闭 |

菜单共有 7 张正方形卡片：传感器、网络、蓝牙、声音、显示、系统、历史。卡片区域可上下滚动，滚动条常显。

## 三、首页与实时监测

- 首页中央是星系吸积动效，默认慢速吸收。
- 右键左滑进入实时监测；左键或返回键右滑回首页。
- 曲线只显示气体阻值 Rs，单位为 kΩ。
- X 轴为时间，每秒追加一个 BME690 样本。
- Y 轴自动量程：0–10 / 20 / 50 / 100 / 200 / 500 / 1000 kΩ。
- 曲线下方参数使用小号字左对齐，不显示“左键返回”等冗余提示。

## 四、检测与结果

1. 首页按确认进入检测页，星系切换为快速吸收。
2. 默认 3.2 秒后完成；也可再次按确认提前完成。
3. 检测完成会把当前温度、湿度、气压和 Rs 写入历史记录。
4. 传感器数据无效时播放“传感器连接异常”，但页面仍进入结果页，避免界面卡死。
5. 结果页不显示伪造食物名称、新鲜度或置信度；推理接入前显示“待接入/待检测/--”。

## 五、声音页

| 项目 | 操作 |
|---|---|
| 音量 | 确认进入编辑，左右每次调节 5，确认保存，返回取消 |
| 提示音开关 | 确认切换；关闭前先播报“功能已关闭” |
| 测试播放 | 确认发送 8 号消息，即使提示音总开关关闭也允许测试 |

注意：当前音量值保存在 ESP32 的 NVS 中；SU-03T 的实际播放音量仍需在模块固件中设置。

## 六、显示页

| 项目 | 操作 |
|---|---|
| 昼夜主题 | 确认切换深色/浅色页面并保存主题选择 |
| 屏幕旋转 | 确认旋转 90°，同时更新 LCD 和 LVGL |
| 亮度 | 确认进入编辑，左右每次调节 10，确认保存，返回取消 |
| 息屏 | 确认关闭背光，任意按键唤醒 |

## 七、网络、蓝牙与系统

- 网络/蓝牙页的确认键只切换本地开关状态；真实连接协议未接入，未连接时顶部图标保持橘黄色。
- 系统页可切换 Modbus 波特率、重启设备或恢复默认设置。
- 重启和恢复默认都需要二次确认，默认选中“取消”。
- 恢复默认后提示音开关会回到开启，亮度回到 100，旋转回到 0°。

## 八、历史记录

- 菜单第 7 张卡片是“历史”，位于第三行最左。
- 使用 NVS 持久化，断电重启后仍保留，最多 20 条，循环覆盖最旧记录。
- 左右键翻记录，确认或返回关闭。
- 每条记录包含序号、温度、湿度、气压、Rs、有效标志。

## 九、提示音触发位置

提示音只放在低频、明确的状态切换点，不给每个按键都配音，避免连续操作时互相打断。

| 消息号 | 事件 |
|---:|---|
| 1 | 开始检测 |
| 2 | 检测完成并保存成功 |
| 3 | 检测取消 |
| 4 | 传感器无效 |
| 5 | 设置保存、旋转屏幕、切换波特率 |
| 6 | Wi-Fi/蓝牙开关开启、提示音重新开启 |
| 7 | Wi-Fi/蓝牙开关关闭、提示音关闭 |
| 8 | 声音页测试播放 |
| 9 | 历史记录保存失败 |

## 十、视觉与交互约束

- 深色和浅色主题都要求高对比度，白色文字不能落在浅色背景上。
- 不显示蓝色方形焦点框；使用与页面主题一致的焦点提示。
- 顶部状态顺序为 Wi-Fi、蓝牙、电池，电池靠最右。
- Wi-Fi/BLE 关闭时隐藏，开启但未连接为橘黄色，真实连接成功才变绿色。
- 菜单标题靠近顶部，卡片高度 66 px，最后一张历史卡片从第三行最左开始。
- 所有用户可见动态提示、Toast、确认框均为中文。
- 新增中文后必须重新检查 12/14/16/20 px 提示字库。

## 十一、演示流程

1. 上电，展示首页星系慢速吸收。
2. 右键进入实时监测，说明 X 轴时间、Y 轴气体阻值和每秒采样。
3. 返回首页，确认开始检测，展示快速吸收。
4. 进入结果页并展示保存后的历史记录。
5. 进入菜单依次展示 7 张卡片、昼夜主题、屏幕旋转和声音测试。
6. 最后说明：推理、真实 Wi-Fi/BLE 和 Modbus 尚未接入，界面不会伪造状态。
