# 硬件接线与电源说明

本文是整机接线的主文档。器件内部原理、封装和采购信息见 `硬件制作\` 与 `器件文档\`。

## 一、系统连接关系

```text
USB / 5V
  ├─ ESP32-S3 N16R8
  │    ├─ SPI2 → ST7789 240×240
  │    ├─ I2C  → BME690
  │    ├─ GPIO → 4 键
  │    └─ UART1 → SU-03T
  └─ SU-03T VCC 5V
       └─ SPK+ / SPK- → 喇叭
```

## 二、ESP32-S3 引脚分配

| 功能 | GPIO | 方向 | 说明 |
|---|---:|---|---|
| LCD SCLK | 12 | 输出 | SPI2 时钟 |
| LCD MOSI | 11 | 输出 | SPI2 数据 |
| LCD CS | 10 | 输出 | 屏幕片选 |
| LCD DC | 9 | 输出 | 命令/数据选择 |
| LCD RST | 14 | 输出 | 屏幕复位 |
| LCD BL | 13 | 输出 | LEDC PWM 背光，高电平点亮 |
| BME690 SDA | 8 | 双向 | I2C 数据，4.7k 上拉 |
| BME690 SCL | 18 | 输出 | I2C 时钟，4.7k 上拉 |
| 左键 | 6 | 输入 | 内部上拉，按下为低 |
| 右键 | 7 | 输入 | 内部上拉，按下为低 |
| 确认键 | 4 | 输入 | 内部上拉，按下为低 |
| 返回键 | 5 | 输入 | 内部上拉，按下为低 |
| SU-03T RX | 15 | 输出 | UART1_TX，接模块 B6 |
| SU-03T TX | 16 | 输入 | UART1_RX，接模块 B7 |
| 调试串口 TX | 43 | 输出 | UART0，接 USB/CH340 |
| 调试串口 RX | 44 | 输入 | UART0，接 USB/CH340 |

禁用或避免：GPIO21/38 已从按键中停用；GPIO17/18 的 UART1 默认复用不能用于语音，因为 GPIO18 已作为 BME690 I2C SCL。

## 三、4 键接线

每个按键只有两端：

```text
左键：GPIO6  — 按键 — GND
右键：GPIO7  — 按键 — GND
确认：GPIO4  — 按键 — GND
返回：GPIO5  — 按键 — GND
```

使用 ESP32 内部上拉。按下时 GPIO 读到低电平，松开为高电平。不需要外部上拉，也不要把按键另一端接 3.3V。

## 四、ST7789 屏幕

- 型号：1.54 寸 ST7789，240×240，8 Pin SPI。
- 供电：3.3V 和 GND，不可接 5V。
- SPI：40 MHz，RGB565，SPI2 DMA。
- 原生窗口：offset=(0,0)，默认 0°。
- BLK 高电平点亮，使用 GPIO13 的 LEDC PWM。

如果屏幕出现偏移，不要直接改 UI 坐标，先核对 ST7789 初始化窗口和旋转值。

## 五、BME690

| 引脚 | 接法 |
|---|---|
| VDD/VDDIO | 3.3V |
| GND | GND |
| SDA | GPIO8，4.7k 上拉到 3.3V |
| SCL | GPIO18，4.7k 上拉到 3.3V |
| CSB | 高电平，选择 I2C |
| SDO | 接地，地址 0x76 |

注意：CSB 如果曾被拉低，芯片会锁存到 SPI 模式，必须断电重新上电。BME690 只直接提供温度、湿度、气压和气体阻值 Rs，不直接提供 TVOC/eCO2。

## 六、SU-03T / LU-03T 语音模块

| 功能 | 接线 |
|---|---|
| 模块供电 | VCC=5V，建议 5V/1A，至少 550mA |
| 共地 | 模块 GND 与 ESP32 GND 相连 |
| ESP32 发消息 | GPIO15 / UART1_TX → B6 / UART1_RXD |
| ESP32 收消息 | GPIO16 / UART1_RX ← B7 / UART1_TXD |
| 串口参数 | 9600 8N1，无流控 |
| 喇叭正极 | 模块 18 SPK+，红线 |
| 喇叭负极 | 模块 17 SPK-，黑线 |

严禁：

- 喇叭接 ESP32 GPIO、3.3V 或 5V。
- SPK+ 或 SPK- 任意一端接 GND。
- 用 ESP32 3.3V 给语音模块供电。
- 把模块 3V3 当输入电源。

完整模块端消息配置见 [SU-03T 提示音串口协议](../器件文档/SU-03T语音模块/提示音串口协议.md)。

## 七、供电与地线

| 电源域 | 负载 | 注意 |
|---|---|---|
| 3.3V | ESP32 逻辑、屏幕、BME690 | 不要给语音模块供电 |
| 5V | SU-03T 功放和喇叭 | 峰值电流大，建议独立 5V/1A |
| USB | 调试和下载 | 注意线和 USB 口电流余量 |

所有 GND 必须共地：ESP32、屏幕、BME690、SU-03T。语音模块功放峰值电流会导致 5V 跌落，出现重启或喇叭破音时先查电源，不要先改代码。

## 八、上电检查顺序

1. 断电，用万用表检查 3.3V 和 5V 对 GND 是否短路。
2. 只接屏幕和 ESP32，上电确认背光和首页。
3. 接 BME690，查看启动日志和温湿度。
4. 接 4 个按键，逐个确认按下为低电平。
5. 接语音模块 5V、GND、喇叭，先听模块出厂提示音。
6. 最后接 UART GPIO15/16，发送测试消息。

## 九、接线验收表

- [ ] 屏幕 3.3V、GND、SPI 6 根线全部正确。
- [ ] BME690 SDA/SCL 有 4.7k 上拉。
- [ ] BME690 CSB 为高，SDO 为低。
- [ ] 4 个按键另一端接 GND，没有接 3.3V。
- [ ] SU-03T VCC 为 5V，电流能力足够。
- [ ] ESP32、屏幕、BME690、SU-03T 共地。
- [ ] GPIO15→B6，GPIO16←B7，没有接反。
- [ ] SPK+ / SPK- 没有接 GND。
- [ ] 上电无异常发热、无异味、无明显电压跌落。
