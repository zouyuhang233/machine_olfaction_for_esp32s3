本教程对应本项目当前的 9 条中文提示音：消息号 1–9，每条不带参数，帧格式 `AA 55 消息号 55 AA`。

> 平台界面可能因版本略有差异，但核心字段不变：产品类别、纯离线方案、SU-03T、UART1、串口输入、消息号、播放语音。

## 一、创建产品

**对应网站：** [智能公元平台](https://www.smartpi.cn/) → 登录 → 产品管理 → 所有产品

1. 登录智能公元，进入 **产品管理 → 所有产品**。
2. 点击 **创建产品**。
3. 产品类别选择 **其他 → 其他产品**。

![步骤1：选择其他产品](01-选择其他产品.png)

4. 场景选择 **纯离线方案**。
5. 模组选择 **SU-03T**。
6. 点击“下一步”。

![步骤2：纯离线方案和 SU-03T](02-选择纯离线与SU03T.png)

产品信息建议：

| 字段 | 建议填写 |
|---|---|
| 产品名称 | 机器嗅觉检测终端 |
| 产品类型 | 其他产品 |
| 场景 | 纯离线方案 |
| 模组 | SU-03T |

## 二、PIN 配置

**对应网站：** [SU-03T 官方资料页](https://docs.aimachip.com/zh-cn/latest/file/offlineVoice/SU03T.html) | [技术开发手册 v1.2](https://docs.aimachip.com/zh-cn/latest/_static/document/SU-03T/SU-03T%E6%8A%80%E6%9C%AF%E6%89%8B%E5%86%8Cv1.2.pdf)

进入产品配置后，打开 **PIN 配置**：

1. `UART1_RX`：配置格式，帧头 `AA 55`，帧尾 `55 AA`。
2. `UART1_TX`：波特率 `9600`，数据位 `8`，停止位 `1`，校验位 `无`。
3. 其他 IO 暂时保持默认，不要占用 UART1。
4. 保存 PIN 配置。

![步骤3：启用 UART1_RX / UART1_TX](03-PIN配置串口.png)

注意：手册截图里 UART1_TX 显示的是 9600，本项目也固定 9600 8N1。ESP32 代码和模块必须一致。

## 三、建立 9 个串口行为

**对应网站：** [智能公元平台](https://www.smartpi.cn/) | [SU-03T 官方资料页](https://docs.aimachip.com/zh-cn/latest/file/offlineVoice/SU03T.html)

对每个消息号新建一个行为。主触发方式统一选择 **串口输入**，串口选择 **UART1_RX**，输入参数保持为空。

| 行为名称建议 | 消息号 | 播报文本 | 发送帧 |
|---|---:|---|---|
| Prompt01Start | 1 | 开始检测 | `AA 55 01 55 AA` |
| Prompt02Done | 2 | 检测完成 | `AA 55 02 55 AA` |
| Prompt03Cancel | 3 | 检测已取消 | `AA 55 03 55 AA` |
| Prompt04SensorError | 4 | 传感器连接异常，请检查 | `AA 55 04 55 AA` |
| Prompt05Saved | 5 | 设置已保存 | `AA 55 05 55 AA` |
| Prompt06On | 6 | 功能已开启 | `AA 55 06 55 AA` |
| Prompt07Off | 7 | 功能已关闭 | `AA 55 07 55 AA` |
| Prompt08Test | 8 | 提示音正常 | `AA 55 08 55 AA` |
| Prompt09SaveError | 9 | 保存失败，请重试 | `AA 55 09 55 AA` |

### 3.1 添加串口触发

**对应网站：** [技术开发手册：串口输入触发](https://docs.aimachip.com/zh-cn/latest/_static/document/SU-03T/SU-03T%E6%8A%80%E6%9C%AF%E6%89%8B%E5%86%8Cv1.2.pdf) | [串口播报视频](https://www.bilibili.com/video/BV1Lapq6xEtx)

1. 在行为中点击 **添加触发**。
2. 触发方式选 **串口输入**。
3. 串口选 **UART1_RX**。
4. 消息编号填写 1 到 9 中对应数字。
5. 输入参数 **不要添加**。
6. 点击确定。

![步骤4：添加串口触发](04-添加串口触发.png)

> 截图里显示 d_char、d_int、d_double 是手册示例。我们的固件不发送参数，所以你的界面不要添加任何参数。

### 3.2 添加播放语音控制

**对应网站：** [技术开发手册：播放语音控制](https://docs.aimachip.com/zh-cn/latest/_static/document/SU-03T/SU-03T%E6%8A%80%E6%9C%AF%E6%89%8B%E5%86%8Cv1.2.pdf) | [串口播报视频](https://www.bilibili.com/video/BV1Lapq6xEtx)

1. 同一个行为里点击 **添加控制**。
2. 控制方式选择 **播放语音**。
3. “是否条件执行”选否，“是否延时输出”选否。
4. 点击 **添加文本**，填写上表中的播报文本。
5. 点击确定，再保存行为。

![步骤5：添加播放语音](05-添加播放语音.png)

每个行为只放一条播放语音即可。后面播放的语音会打断前一条，不要在同一条消息里叠加多个播放控制。

## 四、检查并生成固件

**对应网站：** [智能公元平台](https://www.smartpi.cn/) | [机芯智能帮助文档](http://help.aimachip.com/)

9 个行为全部完成后：

1. 点击 **保存**。
2. 点击 **检查配置**，确认没有空行为、空触发或空播报。
3. 点击 **发布版本 / 生成固件 / 生成 SDK** 中平台显示的对应按钮。
4. 等待平台编译完成，下载固件包。
5. 找到更新固件文件 `uni_app_release_update.bin`。

注意：串口升级需要 `uni_app_release_update.bin`，不要选错成 debug 或非 update 文件。

## 五、烧录接线

**对应网站：** [芯路城 SU-03T 资料下载页](https://www.xinlucity.com/?s=resourcedetail/index/id/82.html) | [SU-03T 官方资料页](https://docs.aimachip.com/zh-cn/latest/file/offlineVoice/SU03T.html)

| SU-03T | USB-TTL / CH340 |
|---|---|
| B7 / UART1_TXD | RXD |
| B6 / UART1_RXD | TXD |
| GND | GND |
| VCC | 独立 5V / 1A |

![步骤6：烧录接线](06-烧录接线.png)

接好后，电脑设备管理器应出现一个 CH340 COM 口。

## 六、使用 UniOneUpdateTool 烧录

**对应网站：** [芯路城 SU-03T 烧录资料](https://www.xinlucity.com/?s=resourcedetail/index/id/82.html) | [机芯智能帮助文档](http://help.aimachip.com/)

1. 打开 `UniOneUpdateTool.exe`。
2. 点击“选择”，选中 `uni_app_release_update.bin`。
3. 确认列表中出现模块对应的 COM 口。
4. 点击“烧录”。
5. 右侧出现“等待设备”后，把模块 GND 断开再重新上电。
6. 等待 `app xx%` 进度走完，出现烧录完成提示。

![步骤7：烧录工具](07-烧录工具.png)

> 如果一直显示等待设备：检查 B6/B7 是否交叉、CH340 驱动、共地、模块 5V 电源和下载口是否正确。

## 七、烧录后接到 ESP32

**对应网站：** [SU-03T 官方资料页](https://docs.aimachip.com/zh-cn/latest/file/offlineVoice/SU03T.html) | [技术开发手册 v1.2](https://docs.aimachip.com/zh-cn/latest/_static/document/SU-03T/SU-03T%E6%8A%80%E6%9C%AF%E6%89%8B%E5%86%8Cv1.2.pdf)

烧录完成并断电重启模块后，把模块从 USB-TTL 改接到 ESP32：

| ESP32-S3 | SU-03T |
|---|---|
| GPIO15 / UART1_TX | B6 / UART1_RXD |
| GPIO16 / UART1_RX | B7 / UART1_TXD |
| GND | GND |
| — | 模块 VCC 接 5V |
| — | 喇叭接 SPK+ / SPK- |

固件已经固定使用 9600 8N1，不要再改模块串口参数。

## 八、逐条测试

**对应网站：** [智能公元平台](https://www.smartpi.cn/) | [串口播报视频](https://www.bilibili.com/video/BV1Lapq6xEtx)

可以先用串口工具发送单帧测试，也可以直接操作 ESP32 界面。

| 测试帧 | 应听到 |
|---|---|
| `AA 55 01 55 AA` | 开始检测 |
| `AA 55 02 55 AA` | 检测完成 |
| `AA 55 03 55 AA` | 检测已取消 |
| `AA 55 04 55 AA` | 传感器连接异常，请检查 |
| `AA 55 05 55 AA` | 设置已保存 |
| `AA 55 06 55 AA` | 功能已开启 |
| `AA 55 07 55 AA` | 功能已关闭 |
| `AA 55 08 55 AA` | 提示音正常 |
| `AA 55 09 55 AA` | 保存失败，请重试 |

ESP32 界面建议测试顺序：

1. 进入声音页，确认“测试播放”播报“提示音正常”。
2. 首页按确认开始检测，应播报“开始检测”。
3. 检测完成应播报“检测完成”。
4. 修改亮度或音量并保存，应播报“设置已保存”。
5. 切换 Wi-Fi/蓝牙开关，应分别播报开启/关闭。

## 九、常见问题

**对应网站：** [机芯智能帮助文档](http://help.aimachip.com/) | [SU-03T 官方资料页](https://docs.aimachip.com/zh-cn/latest/file/offlineVoice/SU03T.html)

| 现象 | 处理 |
|---|---|
| 平台里串口输入没有 UART1_RX | 先到 PIN 配置启用 UART1_RX / UART1_TX |
| 发送消息无反应 | 检查消息号是否 1–9、是否多加了参数、帧尾是否 55 AA |
| 烧录工具找不到 COM | 安装 CH340 驱动，检查 USB-TTL 和线材 |
| 一直等待设备 | 点击烧录后给模块重新上电，检查 B6/B7 交叉和共地 |
| 有声音但 UI 触发不了 | 检查 ESP32 GPIO15→B6、GPIO16←B7，确认 9600 8N1 |
| 播报断断续续 | 检查 5V/1A 电源和共地，避免功放峰值导致掉压 |
