## 新版关键设计

- **U1**：BME690，LGA-8；pin1 GND / pin2 CSB / pin3 SDI / pin4 SCK / pin5 SDO / pin6 VDDIO / pin7 GND / pin8 VDD。
- **C1/C2**：各 **100nF**，分别去耦 VDDIO、VDD（紧靠引脚）。
- **R1/R2**：各 **4.7kΩ**，SDI/SCK 上拉到 VDDIO（I²C 上拉）。
- **H3（接口选择，3P）**：`1=VDDIO`、`2=CSB`、`3=CSB_H`
  - **短接 1-2 → I²C**（CSB 直接接 VDDIO，符合手册 p53 的 direct connection）
  - 短接 2-3 → SPI（CSB 由 H1 的 `CSB_H` 引入）
- **H4（地址选择，3P）**：`1=GND`、`2=SDO`、`3=VDDIO`
  - **短接 1-2 → 地址 0x76**
  - 短接 2-3 → 地址 0x77
- **H1（4P 排针）**：`1 GND`、`2 CSB_H`、`3 SDI`、`4 SCK`
- **H2（4P 排针）**：`1 VDD`、`2 GND`、`3 VDDIO`、`4 SDO`
- **丝印**：已放在顶层，正常可读（不再镜像）。
- **2.54mm 排针**：可直接插面包板／杜邦线。

## 默认用法（I²C，和固件一致）

1. **H3 短接 1-2**（VDDIO—CSB，进 I²C 模式）；
2. **H4 短接 1-2**（GND—SDO，地址 0x76）；
3. H1/H2 与 ESP32-S3 接线：

> 板上丝印顺序：H3 从左到右是 `CSB_H / CSB / VDDIO`（对应 pin3→pin1），所以 **短接 CSB 与 VDDIO 一侧** 就是 1-2；H4 从左到右是 `VDDIO / SDO / GND`（对应 pin3→pin1），**短接 SDO 与 GND 一侧** 就是 1-2。以板上丝印和原理图编号为准。

| 扩展板 | ESP32-S3 |
|---|---|
| H1-1 GND | GND |
| H1-2 CSB_H | 不接（I²C 时由 H3 短接 1-2，CSB 已在板上接 VDDIO） |
| H1-3 SDI | GPIO8（SDA） |
| H1-4 SCK | GPIO18（SCL） |
| H2-1 VDD | 3V3 |
| H2-2 GND | GND |
| H2-3 VDDIO | 3V3 |
| H2-4 SDO | 不接（地址由 H4 选择；SDO 不能悬空） |

> 如果用 SPI：H3 短接 2-3，CSB 从 H1-2 引入；SPI 只是保留能力，当前项目走 I²C。

## 打样/上电前最后确认

- H3、H4 必须有明确短接（不能都悬空）；上电前用万用表确认 CSB 对 VDDIO ≈ 0Ω（I²C 模式）。
- VDD、VDDIO 各 3.3V；C1/C2 在板上。
- **热隔离**：U1 下方禁铺铜、底面 Φ1.0–1.5mm 非金属化孔属于 PCB 层，2D 截图无法核验；打样前请在 EDA 的 3D/Gerber 里再看一眼。若没做，温度调制剖面的重复性会受影响（论文阶段必须处理）。
- 上电顺序：量 3.3V → 读 `chip_id=0x61` → 读 `variant_id=0x02` → 温湿度 → 300°C 加热看 Rs。
