## 〇、原理图部分（对应图3）

你现有原理图里 **C1/C2 已经对了**：C2 在 VDD（pin8）、C1 在 VDDIO（pin6），各 100nF 下地。还要补：

| 位号 | 类型 | 连接 |
|---|---|---|
| **JP1** | 3P 排针 / 跳线 | `1=VDDIO`、`2=CSB(U1 pin2)`、`3=CSB_H(排针 H1 pin2)`；**短接 1-2 进 I²C**，短接 2-3 走 SPI |
| **JP2** | 3P 排针 / 跳线 | `1=GND（地址 0x76）`、`2=SDO(U1 pin5)`、`3=VDDIO（地址 0x77）` |
| R1 / R2（可选） | 4.7k 0805 | `SDI→VDDIO`、`SCK→VDDIO`，板上做 I²C 上拉就不用外挂 |

改完的网络名：排针侧用 `CSB_H`（区别于芯片侧的 `CSB`），其余沿用你已有的 `VDD / VDDIO / GND / SDI / SCK / SDO`。

## 一、改什么（清单）

| # | 改什么 | 为什么 | 优先级 |
|---|---|---|---|
| ① | U1 的 **VDD** 与 **VDDIO** 各加 1 颗 **100nF 0402**，距引脚 ≤2mm | 加热板是电流阶跃负载，没有就近去耦 → 电源塌陷 → 基线漂、气阻跳变、I²C 偶发 NACK | **必改** |
| ② | U1 及四周 **1mm 禁止铺铜**（上下两层），正下方开 **Φ1.0~1.5mm 非金属化孔** | 大面积铜皮+过孔把热量抽走 → 设定温度到不了、随环境温度漂 → **多步加热剖面不可重复** | **必改** |
| ③ | **JP1**：3P 跳线选 CSB（VDDIO / CSB / 排针CSB） | BME690 靠 CSB 电平选接口：**拉高才能进 I²C**，悬空就是 SPI | **必改** |
| ④ | **JP2**：3P 跳线选 SDO（GND=**0x76** / SDO / VDDIO=**0x77**），丝印标出 | 地址由 SDO 决定，且 SDO 不许悬空 | **必改** |
| ⑤ | 右下角手写签名**装饰铜**挪到板边/缩小，别进禁铺区 | 签名横跨 U1 下方，等于在传感器底下铺一大片铜：增热容、扰气流 | 建议改 |
| ⑥ | 所有丝印确认在 **Top 层** | 图上文字全是镜像的；若真在 Bottom，插上面包板看不见标号 | 确认 |

> ⚠️ 关于②：**BME690 的进气口在顶面金属盖上的小孔**，不是底面。所以底面开孔的作用是**减小热耦合、防背部凝露**，不是"通气"。装配时顶面千万别被胶、外壳或泡棉封住。

## 二、在嘉立创 EDA（专业版）里怎么操作

### 1. 加两颗 100nF

- 左侧「元件库」搜 `100nF 0402 X7R 50V`，放 2 颗到 U1 的 VDD / VDDIO 脚旁（丝印标 C1、C2）。
- 走线：U1 引脚 → 电容一端，线宽 0.25mm 以上，长度控制在 2mm 内；
  电容另一端 **就近打 2 个 GND 过孔**（0.3/0.6mm），直接连到 GND 铺铜。
- 别把电容放到板子另一头——去耦电容的作用全靠"近"。

### 2. 禁铺铜

- 选中 GND 铺铜区域 → 右键「铺铜挖空」/「添加禁止区域」，框住 U1 及四周 1mm，**顶层和底层各做一次**。
- 更省事的做法：用「禁止区域」工具画一个矩形（顶层+底层），铺铜会自动避开。
- 检查：用 3D 预览或 Gerber 看，U1 下方应该是空板（基材），没有铜。

### 3. 开通孔

- 「放置 → 焊盘」，类型选**通孔**，孔径 **1.2mm**，**取消"金属化 / Plated"**（要 NPTH）。
- 位置：U1 正中央（`图1` 里红十字的位置）。
- 板厂下单时在备注写：`Φ1.2mm 非金属化孔`，避免被当成过孔金属化。

### 4. 两个跳线

- 放 `HDR-M-2.54_1x3`（3P 2.54 排针）×2，标 JP1、JP2。
- 走线：
  - **JP1**：1 → VDDIO；2 → U1 的 CSB；3 → 排针的 CSB
  - **JP2**：1 → GND（丝印 0x76）；2 → U1 的 SDO；3 → VDDIO（丝印 0x77）
- 想更省高度就把跳线换成 0805 0Ω 焊盘对（二选一焊）。

### 5. 丝印

- 把 `0x76` / `0x77`、`JP1 I2C=1-2`、`JP2 0x76=1-2` 这类文字放到**顶层丝印**。
- 若发现丝印是镜像的：在「图层」里确认文字所属层，或对该文字用「镜像」开关手动翻转。

### 6. 收尾检查

- DRC 全绿；Gerber 预览确认：阻焊、丝印层没有压在 U1 的禁铺区上。
- 打样参数：2 层 / 1.6mm / 常规工艺即可，无特殊要求。

## 三、如果不想再打一版（临时方案）

现有板可以直接用，只要在面包板上补：

1. 外挂 2 颗 100nF（VDD-GND、VDDIO-GND），越靠排针越好；
2. 杜邦线把 `CSB` 短到 `VDDIO`（进 I²C）；
3. `SDO` 接 `GND`（地址 0x76），或接 `VDDIO`（0x77）；
4. I²C 的 SDA/SCL（即 SDI/SCK）各加 4.7k 上拉到 VDDIO；
5. 接受热隔离缺失——**但论文数据阶段必须换板**，否则剖面不可重复。

## 四、改完之后的上电顺序

量 3.3V → 读 `chip_id`（应为 **0x61**）→ 读温湿度 → 300℃ 加热看 Rs 从 MΩ 级掉到几十 kΩ 级 → 再上加热剖面。

> 提示：`chip_id` 也是 0x61，和 BME680/688 一样，**不能用它辨别型号真伪**。

## 五、你这版原理图的复核（2026-11-20，对应 `图4_你这版_待补3处.png`）

**已经对的：**
- C2 → VDD（pin8）、C1 → VDDIO（pin6），各 100nF 下地 ✅
- SDO 固定接 GND → 地址 0x76 ✅（可接受，代价是地址锁死）
- CSB 经一个元件上拉到 VDDIO → 进入 I²C 模式 ✅

**还要处理的 3 处：**

| # | 问题 | 处理 |
|---|---|---|
| ① | **I²C 上拉没做**（必修） | SDI/SCK = SDA/SCL，只接到排针、板上一颗上拉都没有。BME690 无内部上拉，只靠 ESP32 约 45k 的内部弱上拉，短线上 100kHz 也许能通，线一长/速率一高就挂 → **加 4.7k ×2 到 VDDIO** |
| ② | CSB 上拉元件的**阻值要确认** | ⚠️ **已按手册更正（2026-11-20）**：BME690 手册 p53 明确要求 *"a direct connection between CSB and VDDIO is required"*，且 p46 说明 **CSB 被拉低过一次后 I²C 会锁死到下次上电**。所以这里应该是 **0Ω 直连**（或跳线），**不能串 10k 电阻**——电阻上拉在上电/干扰时被拉低一次，芯片就永久切 SPI。 |
| ③ | 地址锁死 0x76 | 想保留可切换性就把 SDO 改成 3P 跳线（或 0Ω 二选一焊盘），否则接受现状 |
