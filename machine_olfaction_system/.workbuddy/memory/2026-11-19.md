## 硬件：BME690 扩展板 v1.0 出图并评审

- 文件：`硬件制作\PCB_PCB1_2026-11-19.png`，2 层板，LGA-8 + 双排 4Pin（`1 GND/2 CSB/3 SDI/4 SCK` ‖ `1 VDD/2 GND/3 VDDIO/4 SDO`），引脚顺序正确。
- **4 处要改**：
  1. **板上没有任何电容** → VDD/VDDIO 各需 100nF 紧靠引脚，否则加热瞬间基线漂、I²C 偶发 NACK。不改板就面包板外挂。
  2. **传感器脚下大面积 GND 铺铜 + 密集过孔** → 热量被 PCB 抽走，设定温度到不了、剖面不可重复，**直接伤"温度调制"的可重复性**；应做禁铺区 + 底面 Φ1.0~1.5mm 通气孔。
  3. **I²C 需外部跳线**：CSB 拉高(VDDIO)才进 I²C；SDO→GND=0x76 / VDDIO=0x77，不许悬空。
  4. **丝印全镜像** → 确认是底层视图还是丝印放错层（放底层则插面包板看不见）。
- 评审清单落在 `硬件制作\BME690扩展板_评审与上电检查.md`。
- 用户明示：**目前不打板，先用模块调试**。
