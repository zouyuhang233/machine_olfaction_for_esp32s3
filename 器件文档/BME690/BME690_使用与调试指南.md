# BME690 使用与调试指南

> 适用：本项目 `machine_olfaction_system`（ESP-IDF）＋ BME690 裸片／扩展板 v1.0。
> 目标：从「焊好/插好但不知道能不能用」走到「能稳定读出温度、湿度、气压、气体电阻 Rs，并能做多步加热剖面」。
> 依据：`BST-BME690-DS001-04`（Rev 1.4，2025-05，60 页，本地 `BST-BME690-DS001_官方数据手册.pdf`）＋ Bosch 官方 `BME690_SensorAPI`（BSD-3，v1.1.0）。

---

## 0. 先记住三件事

1. **BME690 寄存器里没有 TVOC / eCO2**。它只给 **温度、湿度、气压、气体电阻 Rs**；TVOC/eCO2/IAQ 是 Bosch **BSEC** 算法算出来的（闭源、要许可）。所以先用本指南把 Rs 跑稳，再决定要不要上 BSEC。
2. **`chip_id` 不能分辨型号**：BME690/688/680 的 `chip_id` 都是 **0x61**；BME690 要看 **`Variant_Id`（0xF0）= 0x02**。
3. **CSB 必须直接接 VDDIO（0Ω/跳线，不能串电阻）**。CSB 只要被拉低过一次，I²C 就会一直禁用直到重新上电——这是“芯片明明在、就是读不到”的最常见原因（手册 p46 6.1、p53 7.2）。

## 1. 硬件最小系统

### 1.1 BME690 引脚（LGA-8，手册 p52 Table 26）

| 引脚 | 名称 | 接到 | 说明 |
|---:|---|---|---|
| 1 | GND | GND | 地 |
| 2 | CSB | **VDDIO（直连）** | 高 = I²C；被拉低一次 = 锁死 SPI 到下次上电 |
| 3 | SDI | **GPIO8（SDA）** | I²C 数据；**必须外部 4.7k 上拉到 VDDIO** |
| 4 | SCK | **GPIO18（SCL）** | I²C 时钟；**必须外部 4.7k 上拉到 VDDIO** |
| 5 | SDO | **GND** | 地址 LSB：GND = **0x76**；VDDIO = 0x77；**不能悬空** |
| 6 | VDDIO | 3.3V + **100nF 到 GND** | IO 电源（1.2–3.6V） |
| 7 | GND | GND | 地 |
| 8 | VDD | 3.3V + **100nF 到 GND** | 传感器电源（1.71–3.6V） |

> 去耦电容要**紧靠引脚（≤2mm）**。加热瞬间是电流阶跃，没有就近去耦会出现：基线随加热剖面漂、Rs 跳变、I²C 偶发 NACK。

### 1.2 与 ESP32-S3 的接线（和固件默认值一致）

| BME690 | ESP32-S3 |
|---|---|
| 1 GND / 7 GND | GND |
| 2 CSB | 3V3（VDDIO，直连） |
| 3 SDI | GPIO8 |
| 4 SCK | GPIO18 |
| 5 SDO | GND（地址 0x76） |
| 6 VDDIO | 3V3 |
| 8 VDD | 3V3 |

- 两颗 **4.7k** 上拉：SDI→3V3、SCK→3V3（靠近传感器一端）。
- 面包板线尽量短（I²C 先 100kHz；跑稳后再试 400kHz）。
- **不要热插拔**：先断电再插拔传感器；带电插拔容易把 CSB 拉低一次，芯片就锁进 SPI 模式。

### 1.3 用扩展板 v1.0（2026-11-24 更新版）

`硬件制作\BME690扩展板\` 的新版已把电气项做在板上：

1. **C1/C2**：各 100nF（C1=VDDIO、C2=VDD，紧靠 U1）。
2. **R1/R2**：各 4.7k，SDI/SCK 上拉到 VDDIO。
3. **H3 接口选择**：`1=VDDIO / 2=CSB / 3=CSB_H`；**短接 1-2 = I²C**（CSB 直连 VDDIO），短接 2-3 = SPI。
4. **H4 地址选择**：`1=GND / 2=SDO / 3=VDDIO`；**短接 1-2 = 0x76**（固件默认），2-3 = 0x77。
5. **丝印**：已放顶层，正常可读；H1/H2 按板上标号接线。

> 热隔离（U1 下方禁铺铜、底面 Φ1.0–1.5mm 非金属化孔）是 PCB 层的事，2D 图无法确认；打样前在 EDA 的 3D/Gerber 里确认。若没做，温度调制剖面重复性会变差。

> 如果你手上是 **2026-11-19 旧版**：VDD/VDDIO 各外挂 100nF；CSB 用杜邦线短 VDDIO（不能串电阻）；SDO 接 GND（0x76）或 VDDIO（0x77）；SDI/SCK 各外挂 4.7k 上拉到 VDDIO。

## 3. 调试阶梯（按顺序做，每步有验收）

### 第 0 步：上电前检查（万用表）

- 3V3 对 GND 电阻不能接近 0（排除短路）。
- VDD、VDDIO 都等于 3.3V 左右（两个电源脚都要量）。
- SDI/SCK 静态电压约 3.3V（外部上拉正常）。
- CSB 对 VDDIO 电阻 ≈ 0Ω（直连）。
- SDO 对 GND 电阻 ≈ 0Ω（地址 0x76）。

### 第 1 步：I²C 扫描（只验“有没有人应答”）

在 `bme690_init()` 里本质就是读 `0xD0`。预期：

```
I (xxx) bme690: BME690 初始化成功: chip_id=0x61 variant_id=0x02
```

如果日志是 `E_COM_FAIL(I2C?)` 或 `ESP_ERR_NOT_FOUND`，先别怀疑芯片，按顺序查：

1. VDD/VDDIO 是否都有 3.3V；
2. CSB 是否真的到 VDDIO（不是悬空、不是串电阻）；
3. SDA/SCL 是否有 4.7k 上拉到 **VDDIO**（不是 3V3 以外的电平）；
4. SDO 是否接 GND（或 VDDIO）；
5. SDA/SCL 是否接反（GPIO8=SDA，GPIO18=SCL）；
6. LGA-8 焊接是否虚焊（尤其 1、7 脚 GND 和 2 脚 CSB）。

> 用逻辑分析仪/示波器看：起始条件后第 9 个时钟是否有 ACK。有 ACK 没数据 → 寄存器/模式问题；没 ACK → 电气/地址问题。

### 第 2 步：身份识别（验货）

读两个寄存器：

| 寄存器 | I²C 地址 | 期望值 | 说明 |
|---|---:|---:|---|
| `Chip_Id` | 0xD0 | **0x61** | BME680/688/690 都一样，不能区分 |
| `Variant_Id` | 0xF0 | **0x02** | **0x02 才是 BME690**（0x00/0x01 是 680/688 系列） |

固件已在初始化日志里打印；也可以调用 `bme690_chip_id()` / `bme690_variant_id()`。

- `chip_id=0x61, variant=0x02` → 通过，继续。
- `chip_id=0x61, variant≠0x02` → 不是 BME690（或型号被换），先找卖家。
- `chip_id≠0x61` → 读到了别的 I²C 器件，检查地址/总线。

### 第 3 步：软复位 + 校准参数

- 往 **0xE0 写 0xB6** 软复位（效果等同断电重启），等 **5ms**。
- 官方 API `bme69x_init()` 会自动做：软复位 → 读 `chip_id` → 读 `variant_id` → 读两组校准系数。
- 校准系数读错，后面温度/湿度/气压会全部离谱；所以**不要跳过官方 API 自己拼**。

> 调试口诀：**“先复位、再读 ID、再读校准、最后才配置测量”**。顺序反了会出现“读数偶尔对、偶尔全 0”。

### 第 4 步：温度/湿度/气压（先不加热）

配置（和固件默认一致）：

- `ctrl_hum`（0x72）= `0x01`：湿度 1× 过采样
- `ctrl_meas`（0x74）= `(osrs_t=2)<<5 | (osrs_p=5)<<2 | mode=01`
  - `osrs_t=2` → 温度 2×；`osrs_p=5` → 气压 16×；`mode=01` → 强制模式一次
  - 即 **0x55**
- `config`（0x75）= `0x00`（IIR 关闭，先看原始响应）

等约 40–50ms 后读数据：

| 数据 | 地址 | 说明 |
|---|---|---|
| 气压 | 0x1F/0x20/0x21 | 20 位，MSB/LSB/XLSB |
| 温度 | 0x22/0x23/0x24 | 20 位 |
| 湿度 | 0x25/0x26 | 16 位 |

验收（室温、普通室内）：

- 温度约 **15–35°C**，和手机/温度计差 < 2°C；
- 湿度约 **30–70%RH**，和参考差 < 5%RH（未做 reconditioning 时可能偏）；
- 气压约 **95–103 kPa**（海拔不同会有差异）。

> 读数全是 `0x80000` / `0x8000`：对应测量被跳过（osrs=000）或配置写错。
> 湿度长期 0% 或 100%：可能凝露/污染，按手册做 reconditioning（详见 HSMI，datasheet 7.6/7.7 只给指引）。

### 第 5 步：加热与气体电阻 Rs（核心）

BME690 的气体测量 = **加热到目标温度并保持一段时间 → 测气敏层电阻 Rs**。

关键寄存器：

| 寄存器 | 地址 | 作用 |
|---|---:|---|
| `gas_wait_0` | 0x64 | 第 0 步加热时长（1–4032ms 编码） |
| `res_heat_0` | 0x5A | 第 0 步目标加热电阻编码（由目标温度换算） |
| `idac_heat_0` | 0x50 | 初始加热电流（可选，加速起温） |
| `ctrl_gas_0` | 0x70 | `heat_off` bit3：0 = 允许加热 |
| `ctrl_gas_1` | 0x71 | `run_gas` bit5=1 使能气体；`nb_conv` bits3:0=0 选第 0 步 |
| `ctrl_meas` | 0x74 | `mode=01` 触发一次强制测量 |

`res_heat_0` 不是直接写温度，要按手册 p27–29 的公式换算（官方 API 的 `bme69x_set_heatr_conf()` 已实现）：

```
var1 = par_g1/16 + 49
var2 = (par_g2/32768)*0.0005 + 0.00235
var3 = par_g3/1024
var4 = var1 * (1 + var2*target_temp)
var5 = var4 + var3*amb_temp
res_heat_x = (uint8_t)(3.4 * ((var5 * (4/(4+res_heat_range)) * (1/(1+res_heat_val*0.002))) - 25))
```

其中：

- `par_g1/g2/g3` 来自校准系数（0xED、0xEB/0xEC、0xEE 等）；
- `res_heat_range` = 寄存器 **0x02 的 bit5:4**；
- `res_heat_val` = 寄存器 **0x00**（有符号）；
- `amb_temp` 用当前环境温度（可以先固定 25°C，或读温度传感器）。

固件默认 **300°C / 100ms**。读回：

| 数据 | 地址 | 检查 |
|---|---|---|
| `gas_r_msb` | 0x2C | Rs 高 8 位 |
| `gas_r_lsb` | 0x2D | bit7:6 = Rs 低 2 位；bit5 = `gas_valid_r`；bit4 = `heat_stab_r`；bit3:0 = `gas_range_r` |

验收：

- `gas_valid_r = 1` 且 `heat_stab_r = 1`（状态字节常见 **0xB0**：0x80 新数据 + 0x20 气体有效 + 0x10 加热稳定）。
- Rs 在 **几十 kΩ ~ 几 MΩ** 量级（随温度、湿度、气流、污染变化很大，不要拿“某个固定值”当标准）。
- 用手靠近传感器/对传感器哈气，Rs 应明显下降；移开后慢慢恢复 → 说明气敏层在工作。
- `heat_stab_r = 0`：加热时间不够或目标温度太高 → 先把 `gas_wait` 加到 150ms 再试。

> 注意：**第一次上电/焊接后，Rs 基线可能需要几十秒到几分钟稳定**；不要拿上电第一秒的值做标定。

### 第 6 步：重复性（决定能不能做论文）

同一环境、同一加热配置，连续采 **10 个周期**，记录 Rs：

| 次数 | Rs (kΩ) | T (°C) | H (%RH) | heat_stab |
|---:|---:|---:|---:|---:|
| 1 |  |  |  |  |
| … |  |  |  |  |
| 10 |  |  |  |  |

验收建议：

- 10 次 Rs 的变异系数（标准差/均值）**< 5–10%**（面包板阶段先放宽到 10%，打板后应更好）；
- `heat_stab` 必须每次为 1；
- 曲线无周期性跳变（有跳变先查供电去耦/地线）。

### 第 7 步：多步加热剖面（温度调制）

单步 300°C 只是“能测”。项目的核心是 **10 个加热设定点**（`res_heat_x` / `gas_wait_x`，x=0…9）。两种模式：

- **强制模式（forced）**：一次一个步骤，主机控制节奏。简单、好调试，但步骤间有主机开销。
- **并行模式（parallel）**：把最多 10 步写进芯片，芯片自己按剖面跑，TPH 与气体测量并行；适合做温度调制指纹。

固件已封装：

```c
uint16_t temps[10] = {320, 100, 100, 100, 200, 200, 200, 320, 320, 320};
uint16_t durs[10]  = { 50,  50,  50,  50,  50,  50,  50,  50,  50,  50}; // ms
bme690_set_profile(temps, durs, 10, 0);   // shared=0 → 自动按 ~140ms 周期
bme690_reading_t out[10];
uint8_t n = 0;
bme690_read_profile(out, 10, &n);
```

调试要点：

- 每步 `durations_ms` 先都设 **≥ 50ms**；太短会导致 `heat_stab=0`；
- `shared_duration_ms` 是每个 TPHG 序列前的公共等待，先让库自动算；
- 先看 `out[i].gas_index` 是否 0…9 齐全，再看 Rs 随步骤的变化是否**可重复**；
- 剖面数据是“指纹”，不是浓度；要标定必须固定气流、温度、湿度、采样袋体积。

| 地址 | 名称 | 读/写 | 用途 |
|---:|---|---|---|
| 0x00 | `res_heat_val` | R | 加热电阻校正（有符号） |
| 0x02 | `res_heat_range` | R | bit5:4 加热量程 |
| 0x1D | `meas_status_0` | R | bit7 new_data、bit6 gas_measuring、bit5 measuring |
| 0x1F–0x21 | `press` | R | 气压 20 位 |
| 0x22–0x24 | `temp` | R | 温度 20 位 |
| 0x25–0x26 | `hum` | R | 湿度 16 位 |
| 0x2C–0x2D | `gas_r` | R | Rs + gas_range + gas_valid + heat_stab |
| 0x50–0x59 | `idac_heat_x` | R/W | 10 步初始加热电流 |
| 0x5A–0x63 | `res_heat_x` | R/W | 10 步目标加热电阻 |
| 0x64–0x6D | `gas_wait_x` | R/W | 10 步加热时长 |
| 0x6E | `gas_wait_shared` | R/W | 并行模式公共等待 |
| 0x70 | `ctrl_gas_0` | R/W | bit3 heat_off |
| 0x71 | `ctrl_gas_1` | R/W | bit5 run_gas、bits3:0 nb_conv |

| 0x73 | `status` | R | SPI 页选择等 |
| 0x74 | `ctrl_meas` | R/W | osrs_t/osrs_p/mode |
| 0x75 | `config` | R/W | IIR filter / SPI 3线 |
| 0xD0 | `chip_id` | R | 0x61 |
| 0xE0 | `reset` | W | 写 0xB6 软复位 |
| 0xF0 | `variant_id` | R | BME690 = 0x02 |

## 5. 固件怎么用（当前工程）

### 5.1 默认行为

`main/app_main.c` 上电后：

1. 初始化屏幕（横屏 160×128）；
2. 调 `bme690_init(I2C_NUM_0, GPIO8, GPIO18, 0x76)`；
3. 每秒读一次，串口打印：
   ```
   I (12345) app: T=25.31C H=45.20% P=101325.0Pa Rs=123456Ohm status=0xB0 gas_idx=0
   ```
4. 每 2 秒把 T/H/P/Rs 刷到屏上；
5. 传感器没接也不死机：屏幕显示 `BME690 ERR`，后台每 2 秒重试。

### 5.2 改接线/改地址

只改 `components/bsp/include/board_pins.h`：

```c
#define BOARD_BME690_I2C_PORT   I2C_NUM_0
#define BOARD_BME690_SDA        GPIO_NUM_8
#define BOARD_BME690_SCL        GPIO_NUM_18
#define BOARD_BME690_I2C_ADDR   0x76
```

### 5.3 直接调用 API

```c
#include "bme690.h"

ESP_ERROR_CHECK(bme690_init(I2C_NUM_0, GPIO_NUM_8, GPIO_NUM_18, 0x76));

bme690_reading_t r;
while (1) {
    if (bme690_read(&r) == ESP_OK) {
        printf("T=%.2f C, H=%.2f %%, P=%.2f Pa, Rs=%.0f Ohm, status=0x%02X\n",
               r.temperature_c, r.humidity_pct, r.pressure_pa,
               r.gas_resistance_ohm, r.status);
    }
    vTaskDelay(pdMS_TO_TICKS(1000));
}
```

### 5.4 编译/烧写

工程原 README 里的 ESP-IDF v5.1.2 命令模板仍适用；本机验证时用的是 ESP-IDF **v5.5.6**（D 盘安装）。核心命令：

```powershell
idf.py set-target esp32s3

```

串口 **115200 8N1**。看 `bme690` 和 `app` 两个 TAG。

## 6. 故障排查表

| 现象 | 最可能原因 | 处理 |
|---|---|---|
| I²C 完全无应答 | CSB 没接 VDDIO / 接成电阻 / 上电时被拉低过 | 断电，CSB 直连 VDDIO，重新上电；不要热插拔 |
| 有应答但 `chip_id≠0x61` | 地址错/读到别的器件 | 确认 SDO 接 GND=0x76；扫总线看还有谁 |
| `chip_id=0x61`、`variant≠0x02` | 不是 BME690（680/688 冒充） | 找卖家；用 `Variant_Id` 留证 |
| 温度/湿度/气压全 0 或 0x80000 | 测量被跳过、配置写错、校准没读 | 用官方 API 重新 `bme69x_init`；检查 0x72/0x74 |
| 湿度一直 0% 或 100% | 凝露/污染/焊后未恢复 | 按 HSMI 做 reconditioning；避免冷凝环境 |
| `gas_valid=0` | `run_gas` 没置 1、`nb_conv` 不对、加热没配置 | 检查 0x71 bit5；用 `bme69x_set_heatr_conf` |
| `heat_stab=0` | 加热时间太短/目标温度过高/热损失大 | `gas_wait` 加到 150–200ms；检查扩展板铺铜/气流 |
| Rs 跳变/偶发 NACK | 没有 100nF 去耦、地线长、上拉不足 | 就近加 100nF；4.7k 上拉；缩短线；先 100kHz |
| 读数随加热周期性漂 | 热耦合/PCB 散热 | 传感器脚下禁铺铜、开孔、避免外壳压住顶面气孔 |
| 上电第一秒数据离谱 | 基线未稳定 | 预热 30–60s 再采；不要用第一帧标定 |

## 7. 验收清单（硬件 bring-up 完成的标准）

- [ ] `chip_id=0x61`，`variant_id=0x02`；
- [ ] 温度与参考温度计差 < 2°C；
- [ ] 湿度与参考湿度计差 < 5%RH（未做恢复处理可放宽）；
- [ ] 气压在合理范围且随天气/高度缓慢变化；
- [ ] 300°C/100ms 加热时 `gas_valid=1`、`heat_stab=1`；
- [ ] 哈气或靠近少量氨水棉签（**不要接触传感器，禁用乙醇**）Rs 明显变化，移开后恢复；
- [ ] 连续 10 次 Rs 变异系数 < 10%（面包板阶段）；
- [ ] 屏幕能稳定显示 T/H/P/Rs，不花屏、不死机。
