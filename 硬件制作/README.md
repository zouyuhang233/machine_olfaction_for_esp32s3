## BME690 扩展板（2026-11-24 更新版）

- 旧版（2026-11-19）的 4 处评审问题已修正：C1/C2 100nF、R1/R2 4.7k、H3 接口选择、H4 地址选择、丝印顶层可读。
- 默认 I²C：**H3 短接 1-2**（CSB→VDDIO）、**H4 短接 1-2**（SDO→GND，地址 0x76）。
- 详见 `BME690扩展板\README.md` 与 `BME690扩展板\BME690扩展板_评审与上电检查.md`。
- 热隔离（U1 下方禁铺铜、Φ1.0–1.5mm 非金属化孔）需在 EDA 3D/Gerber 最终确认。
