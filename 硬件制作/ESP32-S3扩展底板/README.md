# ESP32-S3 扩展底板 v1.0（叠插式引脚转接）

> 对象：芯路城 **ESP32S3 开发板**（ESP32-S3-WROOM-1 **N16R8**，2×22 = 44 Pin，2.54 mm）。
> 参考页：<https://www.xinlucity.com/?s=resourcedetail/index/id/61.html>（含原理图/尺寸图/引脚定义图附件）。
> 定位：**只做「引脚全部引出 + 电源/接口保护」的叠插转接底板**，不含 BME690/屏/语音等模块电路（那些用飞线或后续整机底板）。
> 交付：`ESP32-S3扩展底板_原理图.png/.pdf`、`ESP32-S3扩展底板_PCB布局.png/.pdf`。

---

## 一、板子规格

| 项目 | 参数 |
|---|---|
| 板框 | **57.15 × 25.4 mm**，四角 **R1.39**（与开发板一致，直接叠插） |
| 与开发板连接 | **2×22 = 44 Pin，2.54 mm 双排叠插排母（长针）**，开发板直接对插 |
| 双排间距 | **22.86 mm**（按板宽 25.4、两侧各留 1.27 边距推算；⚠️ 打样前务必实测，见第六节） |
| 引脚 | 44 脚 **1:1 直通**，长针可从底面插入面包板/洞洞板 |
| 电源输入 | 从开发板 **5V0 / 3V3 / GND** 取电（叠插供电） |
| 电源输出 | **5V_OUT**、3V3_OUT、GND（经保护后由 J3 引出） |
| 保护 | 5V/3V3 各：**PTC 自恢复保险丝 + TVS + 10µF + 100nF**；原生 USB(GPIO19/20) 加 **USBLC6-2SC6 ESD** |
| 其他 | 电源指示灯 LED1；2× Φ2.2 安装孔；丝印全放 Top |

> 说明：这是**纯转接板**，不做稳压。3V3 由开发板稳压器输出（约 1A 上限），5V 直取自开发板 5V0 脚。

## 二、原理图要点

图见 `ESP32-S3扩展底板_原理图.png`。

- **J1 / J2**：两组 1×22 叠插排母（等同一个 2×22 排母的两排）。每个引脚在网络标签上**保留与开发板一致的引脚名**（GPIOxx / 3V3 / 5V0 / GND / RST / USB_D±），方便对照飞线。
- **① 电源保护与分配**
  - `5V0 → F1(PTC 0.5A) → 5V_OUT`，`5V_OUT` 上并 `D1(SMAJ5.0A)`、`C1(10µF)`、`C2(100nF)` 到 GND。
  - `3V3 → F2(PTC 0.5A) → 3V3_OUT`，`3V3_OUT` 上并 `D2(SMAJ3.3A)`、`C3(10µF)`、`C4(100nF)` 到 GND。
  - `3V3_OUT → R1(1k) → LED1 → GND`（电源指示）。
  - `J3`（1×4 排针）：`1=5V_OUT / 2=GND / 3=3V3_OUT / 4=GND`。
- **② 原生 USB 接口保护**
  - `D3 = USBLC6-2SC6`：I/O1←GPIO20(D+)，I/O2←GPIO19(D−)，VBUS←5V_OUT，GND←GND。
  - `J4`（1×4，可选）：`1=5V_OUT / 2=USB_D− / 3=USB_D+ / 4=GND`，用于外接 U 盘/键盘等 USB 设备（仅当开发板 USB OTG 走这两脚时使用）。
- **③ 约束**：GPIO0/45/46（strapping）与 GPIO19/20（原生 USB）**不得加任何上拉/下拉**；GPIO26–32 为 Flash/PSRAM 专用，未引出。
- **串口 TX/RX 已标注**：原理图每个引脚下方用灰/绿小字标出备用功能，其中 **UART0 调试/下载 = GPIO43(TX)/GPIO44(RX)**、**UART1 = GPIO17(TX1)/GPIO18(RX1)** 用绿字突出；PCB 丝印也写成 `GPIO43·TX / GPIO44·RX / GPIO17·TX1 / GPIO18·RX1`。

## 五、打样与装配

- **打样**：2 层 / 板厚 1.6 mm / 1 oz 铜 / 常规工艺；阻焊绿、丝印白；要求不高，**无需阻抗控制**。
- **丝印**：全部放 **Top 层**；方形焊盘 = 1 脚，需与开发板「天线端」方向一致。
- **焊接顺序**：先贴 SMD（F/C/D/R/LED）→ 再焊叠插排母与 J3/J4。
- **装配**：开发板 44 针直接插入 J1/J2；底面长针可插面包板。电源/保护器件**放底面**，避免与开发板器件干涉。
- **上电检查**：量 5V_OUT≈5V、3V3_OUT≈3.3V → LED1 亮 → 再插模块。

## 六、待实测 / 假设（打样前请确认）

1. **双排间距**：本图按板宽 25.4、两侧边距 1.27 推算为 **22.86 mm**。若你手上开发板的排针正好在板边（间距 = 25.4），则底板需加宽约 2×1.27 = 2.54 mm，或把排母外移，否则插不上。**用卡尺量一下两排针中心距最稳妥。**
2. **1 脚 / 方向**：以开发板丝印与天线端为准；本图 J1=左排、J2=右排，若实物方向相反，把两排标签对调即可。
3. **电源**：确认开发板 5V0、3V3 引脚位置与 3V3 的实际供电能力（手册标注约 1A）。
4. **USB 外接**：GPIO19/20 是原生 USB；只有当你把开发板 USB 模式切到 OTG/外接设备时才用 J4，否则 J4 可空贴。

## 七、怎么在嘉立创 EDA / KiCad 里复刻（简要）

1. 建板框 57.15×25.4，R1.39；放 **2×22 2.54 排母** 于两长边（按实测双排间距）。
2. 依次给 44 个焊盘命名网络（对照第三节表）；Power 脚接 3V3/5V_IN/GND，USB 脚接 USB_D±。
3. 按第二节放 `F1/F2 → PTC`、`D1/D2 → TVS`、`C1..C4`、`R1+LED1`、`D3 USBLC6`、`J3/J4`，用网络标签连接。
4. DRC 全绿 → Gerber 预览确认丝印不压焊盘 → 打样。

> 图由 `draw_board.py` 生成（Pillow 绘制，非 EDA 源文件）；如需我改成 **KiCad/嘉立创 EDA 工程源文件**或**加大板型/加装配孔**，告诉我即可。
