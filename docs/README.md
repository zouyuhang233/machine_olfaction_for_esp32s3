## 文档维护规则

1. 引脚、任务、消息号、构建大小变化时，必须同步更新对应文档。
2. 用户可见中文变化时，检查字库是否包含新增字符。
3. 没有实机验证的功能要明确写“待接入”或“未验证”，不能写成已完成。
4. 临时目录、构建产物、独立上位机仓库和日志不进入主仓库。
