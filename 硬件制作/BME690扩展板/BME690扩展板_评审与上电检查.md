## 二、新版原理图核对

### 2.1 BME690 引脚

| U1 引脚 | 连接 | 说明 |
|---:|---|---|
| 1 | GND | 地 |
| 2 | CSB | 经 H3 选择：VDDIO（I²C）或 CSB_H（SPI） |
| 3 | SDI | I²C SDA；R1 4.7k 上拉到 VDDIO |
| 4 | SCK | I²C SCL；R2 4.7k 上拉到 VDDIO |
| 5 | SDO | 经 H4 选择 GND（0x76）或 VDDIO（0x77） |
| 6 | VDDIO | 3.3V；C1 100nF 到 GND |
| 7 | GND | 地 |
| 8 | VDD | 3.3V；C2 100nF 到 GND |

### 2.2 排针

| 排针 | 引脚定义 |
|---|---|
| H1（4P） | `1 GND`、`2 CSB_H`、`3 SDI`、`4 SCK` |
| H2（4P） | `1 VDD`、`2 GND`、`3 VDDIO`、`4 SDO` |
| H3（3P） | `1 VDDIO`、`2 CSB`、`3 CSB_H`；1-2 = I²C，2-3 = SPI |
| H4（3P） | `1 GND`、`2 SDO`、`3 VDDIO`；1-2 = 0x76，2-3 = 0x77 |

### 2.3 默认配置（本项目）

- **H3 短接 1-2**：CSB 直接接 VDDIO，进 I²C；符合手册 p53 “a direct connection between CSB and VDDIO is required”。
- **H4 短接 1-2**：SDO 接 GND，7 位地址 **0x76**（固件默认）。
- 上电前确认 H3/H4 都有短接块，不能悬空。

## 三、上电检查（按顺序）

1. **目视**：U1 1 脚方向、C1/C2、R1/R2 焊位；H3/H4 短接位置。
2. **万用表**：3V3 对 GND 不短路；VDD、VDDIO 均为 3.3V；CSB 对 VDDIO ≈ 0Ω（I²C 模式）；SDO 对 GND ≈ 0Ω（0x76）。
3. **读 ID**：`chip_id`（0xD0）应为 **0x61**，`variant_id`（0xF0）应为 **0x02**（BME690）。
4. **温湿度/气压**：应与参考表接近（温度差 <2°C，湿度差 <5%RH）。
5. **加热与 Rs**：300°C / 100ms，`gas_valid=1`、`heat_stab=1`（状态常见 `0xB0`）；Rs 随哈气/氨水棉签明显变化。
6. **重复性**：连续 10 次 Rs 变异系数 <10%（面包板阶段）；再做多步加热剖面。

## 四、旧版（2026-11-19）临时接法

如果手上还有旧版 PCB（无 C1/C2、无 R1/R2、CSB/SDO 只在排针上）：

- VDD、VDDIO 各外挂 100nF 到 GND，越靠近排针越好；
- CSB 用杜邦线短接 VDDIO（**不能串电阻**）；
- SDO 接 GND（0x76）或 VDDIO（0x77），不能悬空；
- SDI/SCK 各外挂 4.7k 上拉到 VDDIO；
- 接受热隔离缺失，论文数据阶段换新版板。

## 五、焊接提醒

裸片是 LGA-8，焊盘在底面，必须钢网 + 锡膏 + 热风回流（峰值 ≤260°C，焊后锡层高度 ≥50µm）。
焊完按手册做 **reconditioning**（详见 HSMI 文档），否则起始湿度/基线会偏。
