## 两端联调契约（上位机已按此写好，固件照做即可直连）
- 串口 115200 / 8N1 / 无流控，从站 ID 默认 1，轮询周期默认 500ms，响应超时 800ms。
- 上位机 `ChannelConfigWidget::fillExample()` 预置的寄存器表：
  40001 TVOC u16(ppb) / 40002 eCO2 u16(ppm) / 40003-40004 温度 float ABCD /
  40005-40006 湿度 float ABCD / 40007 电池电压 u16 ×0.001 → V。
- Poller 合并规则：同功能码、地址空隙 ≤8 个寄存器合并成一帧，单帧 ≤125 寄存器。

## 上位机可改进点（分析结论，未改代码）
- Poller 某块读失败 → 该块所有通道被写 0 且标无效，曲线出现掉零尖刺；宜保持上次有效值/断线。
- 掉线时每块各等 800ms 超时，一轮 N 块 → 实际周期被拉成 N×800ms；宜加整轮超时/熔断。
- ModbusRtu 无重试（单次超时即放弃），RS485 现场建议重试 1~2 次。
- ChannelModel 的 u32/i32 只有 ABCD/CDAB，缺 BADC/DCBA 字序（float 四种齐全）。
- 配置页未做地址区间重叠校验（float 跨 2 个寄存器时易与相邻 u16 撞车）。
