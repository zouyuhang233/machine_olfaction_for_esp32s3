## 四、故障排查

### 4.1 屏幕白屏、花屏或偏移

1. 检查屏幕 VCC 是否接 3.3V，不能接 5V。
2. 检查 BLK 是否接 GPIO13，并确认高电平点亮。
3. 检查 SCLK=12、MOSI=11、CS=10、DC=9、RST=14。
4. 确认代码里的 offset 是 0,0，旋转是 0°。
5. 确认 SPI 使用 DMA，40 MHz。
6. 如果换过屏幕，先清除 NVS 或恢复默认旋转。

### 4.2 BME690 未找到

1. 检查 VDD/VDDIO 是否为 3.3V。
2. 检查 SDA=GPIO8、SCL=GPIO18 是否接反。
3. 检查 SDA/SCL 是否有 4.7k 上拉。
4. CSB 必须为高，不能悬空或拉低。
5. SDO 接地时地址为 0x76；拉高会变成 0x77。
6. 用扫描工具确认 I2C 地址。
7. 如果 CSB 曾被拉低一次，BME690 会锁到 SPI，需要断电重新上电。

### 4.3 温度或湿度显示异常

- BME690 原始测量已经是 °C 和 %RH，不要重复乘 100。
- 温度显示 0.22°C 或湿度显示 0.39% 时，优先检查单位换算。
- 读数长时间不变时，检查采集任务是否在运行。
- Rs 有效不代表 TVOC/eCO2 有效；后两者在 BSEC 接入前应为 `--`。

### 4.4 按键不灵敏或无响应

1. 确认按键一端接 GPIO，另一端接 GND。
2. 确认引脚为 GPIO6/7/4/5，不是 GPIO21/38。
3. 按下时万用表应读到低电平。
4. 检查是否把 3.3V 接到按键，导致无法拉低。
5. 如果每次切页后都要按两次，检查输入锁是否被误改。

### 4.5 文字缺失或方框

- 说明新增中文字符没有加入 12/14/16/20 px 提示字库。
- 检查 `ui_font_prompt_cn_*.c` 的 symbols 列表。
- 浅色主题白字看不清时，应检查文字颜色和背景对比，不要只加粗字体。
- 数字、度符号、Ω、2 等符号也要加入字库。

### 4.6 SU-03T 没有声音

1. 先确认模块 VCC 是 5V，不是 ESP32 3.3V。
2. 确认模块 GND 与 ESP32 GND 共地。
3. 确认喇叭接 18 SPK+、17 SPK-，没有接 GND。
4. 单独给模块上电，确认出厂开机播报或唤醒词能响。
5. 确认 ESP32 GPIO15 接模块 B6，GPIO16 接模块 B7，不是同向直连。
6. 确认模块串口是 9600 8N1，无流控。
7. 确认模块固件已配置 1–9 号串口输入行为。
8. 用串口工具发送 `AA 55 08 55 AA`，如果仍不响，问题在模块固件或喇叭。
9. 如果模块会响但 UI 不触发，检查提示音总开关和音频页测试项。

### 4.7 编译或烧录失败

- `idf.py` 找不到：先执行 `export.bat`，或使用 ESP-IDF 终端。
- COM 口打不开：关闭串口监视器、SSCOM、Arduino 串口工具等占用程序。
- 连接失败：检查 USB 数据线、CH340/CDC 驱动和开发板下载模式。
- 烧录后仍运行旧固件：确认烧录的是 `machine_olfaction_system.bin`，并查看启动日志版本。
- 构建目录异常：可执行 `idf.py fullclean` 后重新构建。

### 4.8 Git 推送失败

- 确认当前分支为 `main`。
- 确认 GitHub SSH key 可用：`ssh -T git@github.com`。
- 先 `git pull --rebase origin main`，再推送。
- 不要提交 `sim/`、`olfaction-host/`、`aqtinstall.log`、构建产物和临时文件。
