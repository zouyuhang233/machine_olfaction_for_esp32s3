# 1.54 寸 TFT 彩屏（ST7789 / 240×240 / 8 Pin）

## 实物规格

| 项目 | 参数 |
|---|---|
| 显示尺寸 | 1.54 英寸 |
| 分辨率 | 240 × 240 |
| 驱动 IC | ST7789 |
| 接口 | 4 线 SPI（只写） |
| 引脚数 | 8 Pin / 2.54 mm 排针 |
| 工作电压 | **3.3 V**（不要接 5 V） |
| 颜色 | 全彩 RGB |
| 显示区域 | 27.72 × 27.72 mm |
| 工作温度 | -20 ℃ ~ +70 ℃ |
| 触摸 | 无触摸，交互由 6 个外接按键完成 |

实物与商家引脚说明见 [实物与引脚说明.jpg](实物与引脚说明.jpg)。

## 引脚定义与当前接线

| 屏引脚 | 功能 | ESP32-S3 GPIO | 说明 |
|---|---|---|---|
| GND | 地 | GND | 必须共地 |
| VCC | 3.3 V 电源 | 3V3 | 禁止接 5 V |
| SCL | SPI 时钟 | GPIO12 | SPI2 主机 |
| SDA | SPI MOSI 数据 | GPIO11 | 单向写屏 |
| RES | 硬件复位 | GPIO14 | 低电平复位，正常为高 |
| DC | 数据/命令选择 | GPIO9 | 高=数据，低=命令 |
| CS | 片选 | GPIO10 | 低有效 |
| BLK | 背光控制 | GPIO13 | **高电平点亮，低电平关闭**；LEDC PWM 调光 |

> 商家说明原文为“默认打开背光，低电平关闭背光”。固件按高有效 PWM 处理。

## 固件参数

- SPI：40 MHz，Mode 0，DMA，单次最大传输按一行 240×2 = 480 B 配置。
- 像素格式：RGB565（`COLMOD=0x55`）。
- 默认旋转：0°，`MADCTL=0x00`。
- 本批 `YW-T114-V1.0` 实测为**原生 240×240 窗口**，所有方向统一 `offset=(0, 0)`。
- 初始化中发送 `INVON (0x21)`；若某批次颜色反相，可去掉该命令。
- 分辨率是正方形，旋转只改变方向，不改变 LVGL 画布尺寸。

## 当前按键配置

屏模块本身没有按键，使用 6 个独立轻触键，均按下拉低、内部上拉：

| 按键 | GPIO | 主功能 |
|---|---|---|
| UP | GPIO4 | 上移 / 增加 |
| DOWN | GPIO5 | 下移 / 减少 |
| LEFT | GPIO6 | 左移 / 返回 / 减少 |
| RIGHT | GPIO7 | 右移 / 进入 / 增加 |
| OK | GPIO21 | 确认 / 开始检测 / 编辑 |
| BACK | GPIO38 | 返回 / 取消 |

## 排查

1. **顶部约 80 行花屏**：检查驱动偏移；本批模组必须为 `(0, 0)`，加 `(0,80)` 反而会把 UI 下移并裁掉底部。
2. **画面横过来**：把持久化旋转设置为 0°，新固件已自动迁移旧屏留下的旋转值。
3. **背光反了**：确认 BLK 为高点亮；`0%` 应输出低电平，`100%` 应输出高电平。
4. **随机噪点**：先降到 30 MHz 或 20 MHz，缩短飞线并确认 GND 回流。
5. **白屏/黑屏**：确认 3.3 V、共地、RST 与 CS 接线，再检查 SPI SCLK/MOSI 是否接反。
